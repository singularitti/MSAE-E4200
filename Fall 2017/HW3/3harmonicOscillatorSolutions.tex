\[-kx = m \frac{d^2x}{dt^2}\label{eq:kx}\]

This is a mathematical solution of \eqref{eq:kx}.

\st{
From middle-school math, we know $\omega_0 = \sqrt{\frac{ k }{ m }}$,
usually called \emph{natural frequency}.
You can think this
formula is a HO with an initial displacement without initial velocity. 
By the way, this is not the most general solution. 
Since we can start with $x = 0$ and give it a kick, so the HO has non-zero velocity.
We will talk about it later.
}

\st{
From middle-school math, we know that $\cos$ is a function of periodicity $2\pi$.
And the solution \eqref{eq:-x} follows this form. In order to change $\omega_0 t$ by $2\pi$, we need time to evolute $\frac{ 2\pi }{ \omega_0 }$, this is called the period of one complete oscillation.
}

\[T = 2\pi\sqrt{m/k}.\]

{\bfseries some extra questions:} How is the motion affected by the mass of the block? By the stiffness of the spring? By the amplitude of the initial displacement? What does the spectrum of this system look like?  What are the allowed energies of this system?

\st{
If $m$ increases, natural frequency $\omega_0$ decreases. The periodicity increases,
means the HO needs longer time back to its equilibrium position, and \textit{vice versa}.
If the spring becomes stiffer, i.e., $k$ is larger, 
thus larger restoring force, then
$\omega_0$ increases,
$T$ decreases, thus the spring needs less time to recover, or, it oscillates faster, and
\textit{vice versa}.
$A$, the amplitude of initial displacement will not affect the periodicity,
though it does affect the displacement and velocity at time $t$.
Unlike quantum harmonic oscillators, which have discrete energy levels, classical HOs
have continuous energy levels. The lowest possible energy is $0$, again different from
QHO, which needs lowest energy to be $\frac{ 1 }{ 2 } \hbar \omega$(zero-point energy). There is no restriction on highest possible energy.
}

\st{
If we do not observe the motion at $0$ but some other time $t_0$, then the motion
from $t_0$ can be expressed as 
}
\[x = A\cos(\omega_0 (t-t_0)),\]
\st{
Inside $\cos$, we call it \emph{phase},
and we let $\omega_0 t = - \phi$ for conveniently speaking the component which
does not depend on time, and give it a name \emph{initial phase}, that is,
}

\[x = A\cos(\omega_0t + \phi). \label{eq:gsa}\]

\st{
By imposing middle-school formula, $\cos (\alpha + \beta) = \cos(\alpha) \cos(\beta) - \sin(\alpha) \sin(\beta)$,
we arrive at
}
\[x = C\cos(\omega_0t)+ D\sin(\omega_0 t),\]
\st{
$C = A \cos(\phi)$, $D = -A \sin(\phi)$. But this is just math tricks.
Now let's talk about physics.
}

\st{
Rewrite \eqref{eq:gsa}, but now $A = a$ means oscillation amplitude, where $x$ has unit \si{\meter}:
}
\[x = a \cos(\omega_0t + \phi), \label{eq:xx}\]
\st{
we differentiate $x$ and obtain velocity
}

\[v = -\omega_0 C\sin(\omega_0t)+\omega_0 D\cos(\omega_0t)\]
\st{
it can be repacked to a simpler form:
}

\[v=-\omega_0 a \sin(\omega_0t+\phi). \label{eq:vv}\]
\st{
We have two undetermined constants $C$ and $D$, assume we already know
the initial displacement $x_0$ and $v_0$, apply to \eqref{eq:xx} and \eqref{eq:vv},
we got
}

\[C = x_0,\]
\st{
and
}

\[v_0 = \omega_0 D.\]
\st{
Thus,
}

\[D= v_0/\omega_0 \]
\st{
Now the explicit form of $x$ and $v$ can be written out.
}

\st{
The potential energy at any moment is $\frac{ 1 }{ 2 } k x^2$, where $x$ is the displacement and $k$ is the spring constant, substitute \eqref{eq:xx}, we get
}
\[U = \frac{1}{2}kx^2 = \frac{1}{2}ka^2\cos^2(\omega_0t+\phi). \label{eq:uu}\]
\st{
The potential energy is not constant; the potential never becomes negative. There is always some energy in the spring, but the amount of energy fluctuates with $x$. 
}

\st{
The kinetic energy is $\frac{ 1 }{ 2 } m v^2$, substitute \eqref{eq:vv} we get
}
\[T = \frac{1}{2}mv^2 = \frac{1}{2}m\omega_0^2a^2\sin^2(\omega_0t+\phi).\]
\st{
The kinetic energy is $0$ when $x$ is at the maximum, because then there is no velocity; on the other hand, it is maximal when $x$ is passing through $0$, because then it is moving fastest.
}

\st{
The total energy is conserved since
}
\[T+U = \frac{1}{2}m\omega_0^2a^2(\cos^2(\omega_0t+\phi)+\sin^2(\omega_0t+\phi))=\frac{1}{2}m\omega_0^2a^2 = \frac{ 1 }{ 2 } k a^2.\]
\st{
where $a$ and $k$ are constants for a certain spring. 
This is true since no friction appears here.
This means 
variation of the kinetic energy is just the opposite of that of the potential energy.
}

\begin{equation}
  P(t) = F(t) \dot{x}(t) = -\frac{ F_0^2 \omega }{ m(\omega_0^2 - \omega^2) } \cos (\omega t) \sin (\omega t),
\end{equation}
so average power is
\begin{equation}
\begin{split}
  \langle P \rangle = \frac{ \omega }{ 2\pi } \int_{0}^{2\pi/\omega} P(t) dt
  &= -\frac{ \omega }{ 2\pi } \int_{0}^{2\pi/\omega}
  \frac{ F_0^2 \omega }{ m(\omega_0^2 - \omega^2) } \cos (\omega t) \sin (\omega t)\, dt= 0.
\end{split}
\end{equation}

\begin{equation}
  U(t) = \frac{ 1 }{ 2 } k x^2 = \frac{ 1 }{ 2 } m \omega_0^2 C^2 \cos^2 (\omega t),
\end{equation}
and
\begin{equation}
  T(t) = \frac{ 1 }{ 2 } m v^2 = \frac{ 1 }{ 2 } m \omega^2 C^2 \sin^2 (\omega t).
\end{equation}

\begin{align}
  \langle U \rangle &= \frac{ \omega }{ 2\pi } \int_{0}^{2\pi/\omega} U(t) dt =

  \langle T \rangle &= \frac{ \omega }{ 2\pi } \int_{0}^{2\pi/\omega} T(t) dt = 
  \frac{ 1 }{ 4 } m \omega^2 C^2.
\end{align}

The total energy is
\begin{equation}
\langle E \rangle = \langle U \rangle + \langle T \rangle = \frac{ 1 }{ 4 }
\frac{ F_0^2 (\omega^2 + \omega_0^2) }{ m (\omega_0^2 - \omega^2)^2 }.
\end{equation}

\section*{Complex number representation}
[Keep going writing the logic that explains the equations you see.  Make it like a story that can be read like a novel.]

\st{
Physicists like to use complex number representation for describing periodic motions as in this case. A complex number can be written in the form of real part and imaginary part:
}
\[a = a_r + ia_i = x + iy\]
\st{
Or can be written in the form of magnitude and phase:
}

\[x+iy = re^{i\theta}\]
\st{
The magnitude of a complex number can be taken by multiplying itself with its complex conjugate, which gives the square of magnitude:
}

\[aa^*=(x+iy)(x-iy)=r^2e^{i\theta}e^{-i\theta}=r^2\]
\st{
An important formula for complex number is the Euler's formula, which says the exponent of a pure imaginary number has a cosine for its real part, and a sine for its imaginary part. In this way, the $\cos(\omega t)$ we used before is simply the real part of the complex exponential function $e^{i\omega t}$:
}

\[e^{i\omega t}=\cos{\omega t}+i\sin(\omega t)\]
\st{
And we can write $F(t)$ as the real part of a complex function $F_0 e^{i\omega t}$:

}

\[F(t) = \Re(F_0e^{i\omega t})\]
\st{
We can also use complex phase in representing an oscillation phase. If the oscillation phase can be written as $\cos(\omega t - \phi)$, we can simply put the phase argument into a complex exponential, so that
}

\[F(t) = F_0e^{i(\omega t-\phi)}\]
\st{
We will eliminate the real part symbol ``R", and simply use complex number for representing physical quantities. On one hand, a complex number is simply a combination of real part and imaginary part, both of which can be treated as solutions to the equations we solve. As our differential equations are usually linear, we can always take the real part at any step to get the real physical quantity we need. Moreover, it is conventional that when treating physical quantities oscillating with a given frequancy $\omega$, the real part and imaginary part stands for two oscillating components that are 90 degree out of phase with each other. We always define the real part (cosine term) as the in-phase component, and the imaginary part (sine term) the out-of-phase component. The $e^{i\omega t}$ phase is also called ``reference phase", as any phase in oscillation is taken with respect to this phase. As in this case, we can separate the $e^{i\omega t}$ term and leave the constant term into a complex number called complex amplitude of oscillation:
}

\[F = F_0e^{-i\phi}e^{i\omega t}=\widehat{F}e^{i\omega t}\]
Can we use this complex number formulation to actually solve a real differential equation problem? e.g.,
\[\frac{d^2x}{dt^2}+\frac{kx}{m} = \frac{F}{m}=\frac{F_0}{m}\cos(\omega t).\]
Naively, let's assume there is such a thing as a complex force and a complex displacement (there isn't) but let's see what happens
\[\frac{d^2(x_r+ix_i)}{dt^2}+\frac{k(x_r+ix_i)}{m} = \frac{(F_r+iF_i)}{m}\]
\[\frac{d^2x_r}{dt^2}+\frac{kx_r}{m}+i\left(\frac{d^2x_i}{dt^2}+\frac{kx_i}{m}\right)= \frac{F_r}{m}+i\frac{F_i}{m}\]
[draw a conclusion.  Don't solve it, but discuss what would happen if the spring restoring force was proportional to $-kx^2$.]

\st{
As we can see, this differential equation is a linear equation, and we can simply combine two solutions $x_r$ and $x_i$ into a new solution $\hat{x} = x_r + ix_i$. However, if we consider a nonlinear system whose spring restoring force is proportional to $-kx^2$, then the principle of superposition no longer hold. We would not expect a solution in a harmonic oscillating form, but something more complicated, and it would be pointless to use Euler's formula and replace $\cos(i\omega t)$ \& $\sin(i\omega t)$ with $e^{i\omega t}$.
}

OK, we are ready:
\[\frac{d^2 x}{dt^2}+\frac{k x}{m} = \frac{\widehat{F}}{m}e^{i\omega t}\]
\st{
  Here we use $\hat{x}$ for the complex amplitude, while the complete oscillating function is
}

\[x = \hat{x}e^{i\omega t}\]
\st{
Eliminating all the reference phase terms, we get

}

\[(i\omega)^2\hat{x}+(k\hat{x}/m)=\widehat{F}/m\]
\st{
When taking time derivative to the oscillating function $x$, the $e^{i\omega t}$ term yields a factor $i\omega$, while other terms remain constant. Therefore, we can simply replace all the $d/dt$ operators with $i\omega$ factors. Solving directly for $\hat{x}$, we get the complex amplitude of oscillation:
}

\[\hat{x}=\frac{\widehat{F}/m}{(k/m)-\omega^2}\]
\st{
Replacing $k/m$ with the natural frequency $\omega_0$, we get

}
\[\hat{x}=\frac{\widehat{F}}{m(\omega_0^2-\omega^2)}.\]

\section*{Forced oscillator with damping}
\st{The complex number representation for solutions of oscillator problems just provides a mathematical vehicle that allows more complex problems to be solved analytically, such as a damped, driven, harmonic oscillator.  This is important because although we have received good insights from undamped oscillator, damping is a fact of life in the real world so we really want to be able to handle it.
  
  Damping implies a frictional term which can be very complicated in general, but to begin with we can think about a straightforward one that is, nonethess, of some physical relevance.  This is where the friction force is proportional to the velocity of the particle.  This is a good approximation if the mass on the spring is moving through oil for example.  If the mass is stationary there is no force, and the faster the mass is moving the greater the force, and we assume that it is linear because, well, why?}

\[F_c = -c\frac{dx}{dt}\]
\st{
  where $F_c$ is the frictional force, $\frac{dx}{dt}$ is the velocity of the mass, and c is the coefficient. It will be convenient, in our mathematical analysis, to write the constant c as m times γ to simplify the equation a little. The minus sign indicates the fact that the direction of the friction is opposite the direction of the velocity.
  Now, we can write out the corresponding 2nd order differential equation with constant coefficients for the damping oscillator 
}
\[ F(t) = m \frac{d^2x}{dt^2}+c\frac{dx}{dt}+ kx\label{eq:dkx}\]
\st{
  By replacing $c$ by $m\gamma$, and $k$ by $m\omega_0^2$, we have
}
\[ \frac{F}{m} = \frac{d^2x}{dt^2}+\gamma\frac{dx}{dt}+ \omega_0^2x \label{eq:damping}\]

\st{
  Then we apply the complex number representation again. We write $F$ as the real part of $\hat{F} e^{i \omega t}$ and $x$ as the real part of $\hat{x} e^{i \omega t}$, and substitute these into Eq. \eqref{eq:damping}
}
\[[(i\omega)^2\hat{x}+\gamma(i\omega)\hat{x}+\omega_0^2\hat{x}]e^{i\omega t}=(\widehat{F}/m)e^{i\omega t}\]
\st{
  If we divide by $e^{i \omega t}$ on both sides, then we can obtain the response $\hat{x}$ to the given force $\hat{F}$.
}
\[\hat{x} = \frac{\widehat{F}}{m(\omega_0^2-\omega^2+i\gamma\omega)} \label{eq:hatx}\]
\st{
  $\hat{x}$ is given by $\hat{F}$ times a certain factor. There is no technical name for this factor, we may call it $R$ for discussion purposes:
}
\[R = \frac{1}{m(\omega_0^2-\omega^2+i\gamma\omega)}\]
\[\hat{x} = \widehat{F}R \label{eq:xfr}\]
$R$ is also a complex number. We may write it as the real part plus the imaginary part or the magnitude times the phase:
\[R=p+iq\]
or
\[R=\rho e^{i\theta}\]
\st{
  Eq. \eqref{eq:xfr} tells us that $\hat{x}$ is equal to $\hat{F} R$ . So, writing $R=\rho e^{i\theta}$ as another name for $R$, we get
}
\[\hat{x} = \widehat{F}R=\rho e^{i\theta}F_0e^{i\phi}=\rho F_0e^{i(\theta+\phi)}\]
\st{
  Finally, going even further back, we see that the physical $x$, which is the real part of the complex $\hat{x} e^{i \omega t}$, is equal to the real part of $\rho F_0 e^{i(\theta+\phi+\omega t)}$. But $\rho$ and $F_0$ are real, and the real part of $e^{i(\theta+\phi+\omega t)}$ is simply $\cos(\omega t+\theta+\phi)$.
}
\[x = \rho F_0 \cos(\omega t + \phi + \theta)\]
[in broad terms, what does the amplitude of the oscillation depend on? What is the meaning of the terms in the argument of the cosine?
Describe this in terms of language consistent with a system forcing and a system response.]
\st{
  This tells us that the amplitude of the response is the magnitude of the force $F$ multiplied by a certain magnification factor $\rho$; this gives us the “amount” of oscillation. It also tells us that $x$ is not oscillating in phase with the force, which has the phase $\phi$, but is shifted by an extra amount $\theta$. Therefore $\rho$ and $\theta$ represent the size of the response and the phase shift of the response.
  
  Now let us work out what $\rho$ is. If we have a complex number, the square of the magnitude is equal to the number times its complex conjugate
}
\[\rho^2 = \frac{1}{m^2(\omega_0^2-\omega^2+i\gamma\omega)(\omega_0^2-\omega^2-i\gamma\omega)}\label{eq:rho2}\]
\[= \frac{1}{m^2[(\omega_0^2-\omega^2)^2+\gamma^2\omega^2]}\]
\st{
  In addition, the phase angle $\theta$ is easy to find, for if we write
}
\[1/R = 1/\rho e^{i\theta}=1/(\rho e^{-i\theta})=m(\omega_0^2-\omega^2+i\gamma\omega)\]
\st{
  $\tan(\theta)$ can also easily calculated by taking the ratio of imaginary part to real part
}
\[\tan(-\theta)=\frac{\gamma\omega}{(\omega_0^2-\omega^2)}\]
\[\tan(\theta)=-\frac{\gamma\omega}{(\omega_0^2-\omega^2)}\]
[sketch or plot $\rho^2$ and $\theta$ vs. $\omega$ ]

In the vicinity of a resonance (where $\omega \sim \omega_0$, and for the case where the friction term is small, we can find an
approximate expression for Equation~\ref{eq:rho2}.)
\st{
  Since $\omega_0^2 - \omega^2=(\omega_0 - \omega)(\omega_0 + \omega)$, if $\omega$ is near $\omega_0$ this is nearly the same as $2 \omega_0 (\omega_0 - \omega)$ and $\gamma \omega$ is nearly the same as $\gamma \omega_0$. Using these in \eqref{eq:hatx}, we see that
}
\[\omega_0^2-\omega^2+i\gamma\omega \sim 2\omega_0(\omega_0 - \omega + i\gamma/2)\]
\st{
  It is easy to find the corresponding formula for $\rho^2$
}
\[\rho^2 = \frac{1}{4m^2\omega_0^2[(\omega_0-\omega)^2+\gamma^2/4]}\]
\st{
  if we call the maximum height of the curve of $\rho^2$ vs. $\omega$ one unit, and we ask for the width $\Delta\omega$ of the curve, at one half the maximum height, the full width at half the maximum height of the curve is
}
\[\Delta\omega = \gamma\]
\st{
  supposing that $\gamma$ is small. The resonance is sharper and sharper as the frictional effects are made smaller and smaller.
  
  As another measure of the width, some people use a quantity $Q$ which is defined as
}
\[Q=\omega_0/\gamma\]
\st{
  The narrower the resonance, the higher the $Q$: $Q=1000$ means a resonance whose width is only 1000th of the frequency scale.
}

This is not required by the homework but a general solution to equation
\begin{equation}
\frac{ d^2 x }{ dt^2 } + 2 \gamma \frac{ dx }{ dt } + \omega_0^2 x = \frac{ F_0 }{ m }
\cos (\omega t)
\end{equation}
is
\begin{equation}\label{eq:gs2}
x(t) = \frac{ F_0 }{ m \sqrt{(\omega^2 - \omega_0^2)^2 + (2 \gamma \omega)^2} }
\cos (\omega t + \varphi) + e^{-\gamma t} \big(
A f(t) + B g(t)
\big),
\end{equation}
where
\begin{equation}
\tan \varphi = \frac{ 2 \gamma \omega }{ \omega^2 - \omega_0^2 }
\end{equation}
and
\[
f, g =
\begin{cases}
\cos(\sqrt{\omega_0^2 - \gamma^2} t), \sin(\sqrt{\omega_0^2 - \gamma^2} t)  &  \text{underdamped case}, \\
1, t    &  \text{critical damping}, \\
\cosh(\sqrt{\gamma^2 - \omega_0^2} t), \sinh(\sqrt{\gamma^2 - \omega_0^2} t)
& \text{overdamping}.
\end{cases}
\]
The first term of \eqref{eq:gs2} is a particular solution or called "steady-state" solution,
the second term of it is a general solution or called "transient" solution.\footnote{
See \url{https://www.andrew.cmu.edu/course/33-231/shm.pdf} for more detail.
